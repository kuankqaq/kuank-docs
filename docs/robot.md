# 机器人文档
> 群内主要机器人为`宽宽备用bot`电报群也有bot，QQ群中官方bot,也就是带蓝标的，也算是我的，所以所有机器人问题请先私信宽宽
[] 表示必填 <>表示选填
所有机器人命令如下
- /签到
用法: 使用时获得30金币，第一次签到赠送30金币

- /工坊 [url]
用法：填入工坊链接后自动解析工坊下载直链

- 档案插件
/档案列表
用法：使用时展示出所有群里已存档的档案

/下载档案 [id]
用法：填入档案id后自动发出档案详情的压缩包

- /十连
用法：自动生成出明日方舟的十连图，包括所有角色
由斯卡蒂bot移植

- /数字炸弹
用法：输入后自动返回帮助面板

- /三方
用法：自动查询当日三方信息，没有自动不返回

- /今日运势
用法：自动返回运势卡片
别名 /jrrpmax
也是移植的

- 查服插件
/l4 <组名> [id]
没啥用，查单个服

/l4_all
返回所有服的统计信息

/connect <ip[:port]>
查询自定义求生之路2服务器，不填端口默认27015

/l4_find [组名] <玩家名>
找人的，不过好像用不上

- /战绩 <@qq>
用法：不@默认查询自己，返回宽服的服务器统计信息
别名 /查询数据

- /img
用法：随机返回一张二次元照片
API:https://www.loliapi.com/
别名 /图片

- /俄罗斯转盘
用法：发送指令自动获取游戏有关帮助菜单
别名 /恶魔轮盘赌

- /地图 [name]
用法：填入名称自动获取地图站中符合的地图，可以使用地图代码，地图中英文名称

- 个人信息插件
/登记 [Steam好友码|ID64|ID32]
用法：用于没有登记记录时补登记
入群验证消息自动绑定Steam

/查 <@qq>
用法：默认查询自己的Steam在线，游玩游戏信息，@人则查询被@的信息

/反查 [name]
用法:利用steam名称反查是否在群里，查到则自动@

- 网易云插件
/发送模式 [语音|文件|卡片]
用法：改变使用该插件时音乐的发送方式

/歌单标签
用法：展示所有受支持的标签

/点歌 [name] <count>
用法：填入名称自动选择搜索结果的第一个，填入数量自动显示搜索结果

/来首好歌 <tag>
用法：不填标签自动随机抽取，填入歌单标签后自动从所给标签中抽取
